# May 18, 2026 - Prompt injection in unity-explorer Claude PR review workflow

|                          |             |
| -----------------------: | :---------- |
| **Reported on Immunefi** | May-18-2026 |
|           **Mitigation** | May-18-2026 |
|   **Solution Completed** | May-18-2026 |

## Description

- The `claude-pr-review.yml` workflow in `decentraland/unity-explorer` checked out the attacker-controlled PR head and loaded `.github/prompts/review-instructions.md` from that untrusted checkout, injecting its contents directly into the Claude prompt while the job held write permissions for PRs/issues/statuses and access to repository secrets.
- A malicious PR could overwrite the instructions file to coerce the agent into exfiltrating `GITHUB_TOKEN`, `ACTIONS_RUNTIME_TOKEN`, or other secrets (Unity, Epic Store, AWS, SSH, Sentry, etc.) via PR comments, enabling cache poisoning, supply-chain compromise, and abuse of downstream release infrastructure.

## Severity

Websites & Applications - Critical.

## Solution

[Load the review instructions from the trusted base branch instead of the PR checkout](https://github.com/decentraland/unity-explorer/pull/8790) so PR-controlled content can no longer influence the Claude agent's operational instructions.
